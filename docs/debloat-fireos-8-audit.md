# Fire TV debloat audit — Hisense 55E6QF, Fire OS 8.1.8.0 (read-only)

> Nothing below disables anything. Every change needs the shown package list
> plus explicit approval, one package at a time, with a core-function check
> after each. `tools/debloat-audit-fireos8.sh` only inspects.

## How to audit (non-destructive)

```sh
TV=<tv-ip> tools/debloat-audit-fireos8.sh   # package list, disabled list, getprop, settings
```

Back up before anything: `pm path com.gathin.tvhome` + `adb pull`, `dumpsys
package com.gathin.tvhome`, `settings get secure enabled_accessibility_services`,
`settings get secure screensaver_components`, the Home resolver. Record the
signing cert (`apksigner verify --print-certs`). Keep stock Home enabled.

## Categories (verify each name on the TV with `dumpsys package <name>`)

- Essential system services — never touch: `android`, `com.android.systemui`,
  `com.android.phone`, `com.android.settings`, `com.android.tv.settings`,
  `com.android.providers.*`, permission controller / package installer /
  ext services (`com.android.*`, `com.google.android.*` where present),
  `com.amazon.tv.launcher` (stock Home — recovery path), `GuiardRevival`
  dependencies, `com.gathin.tvhome` + `HomeRedirectService`.
- Home/launcher dependencies: keep stock Home + Quiet Machine redirect.
- Hardware/input: keep HDMI/tuner/input services, remote/BLE pairing, on-screen
  keyboard, Wi-Fi/Bluetooth stacks.
- Miracast/media: keep `com.amazon.tv.settings` display/mirroring paths,
  Wi-Fi Display / Cast services, playback/DRM components.
- Streaming apps in use — keep: Netflix, Prime Video, YouTube, HBO Max,
  Spotify, Instagram (confirm exact package names on the TV first).
- Optional telemetry / advertising / recommendations: only candidates for
  `pm disable-user --user 0`, after approval, one at a time.
- Unused preinstalled apps: candidates only when confirmed unused and not a
  dependency of a kept feature.

## Safety rules

- Disable, never uninstall. `pm disable-user --user 0`, one package per call.
- Stop at the first regression and restore that package:
  `pm enable <package>` (exact restore commands are generated by the audit
  script from the pre-change state).
- Never disable firmware updaters to chase a count; never touch factory/test
  packages; never change unrelated firmware behaviour.
- Aggressive counts are out of scope. Fewer, verified disables beat more.
